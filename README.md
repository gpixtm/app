# Gpix

Offline-first Flutter hiking app with a central GPX map, automatic offline maps, walking navigation, day planning, walk history and optional Health Connect measurements. English and French are supported; change language before sign-in or in Settings.

- Start with [agent instructions](AGENTS.md) for code, language and delivery rules.
- Follow [development setup](docs/DEBUG-VSCODE.md) to run against a LAN API or HTTPS production.
- Read [product decisions](docs/PRODUCT.md) and [localization workflow](docs/LOCALIZATION.md) when changing behavior.
- Regenerate the logo, launcher icon and splash from the [brand assets guide](docs/BRANDING.md).

This repository contains the mobile app only. The separate API repository is `gpixtm/api`. Develop on `develop`; commits and merges follow the explicit approval sequence in `AGENTS.md`.
