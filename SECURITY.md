# Security policy

Please **do not open a public issue** for a vulnerability. Report it privately through GitHub's [private vulnerability reporting](https://github.com/gpixtm/app/security/advisories/new) for this repository, with the affected version, reproduction steps and the impact you expect.

We aim to acknowledge reports within a week and will keep you informed until a fix is released. Only the latest release is supported.

Server-side issues can be reported the same way on [gpixtm/api](https://github.com/gpixtm/api/security/advisories/new).
